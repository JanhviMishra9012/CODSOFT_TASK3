# Music Player

A music player built with plain HTML, CSS, and JavaScript, styled with a glassmorphism look and dark/light mode.

## Files

- `index.html`
- `styles.css`
- `script.js`

## How to run

Keep all three files in the same folder, then just open `index.html` in your browser. No installation or server needed.

To add your own songs, edit the `tracks` array at the top of `script.js` with your audio file paths and poster images.
